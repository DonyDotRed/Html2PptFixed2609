사용법

왼쪽에 HTML을 넣고 슬라이드 만들기를 누르면 문서가 장 단위로 잘려 슬라이드가 됩니다. 가운데에서 결과를 확인하고, 오른쪽에서 내용과 모양을 고친 뒤 PPTX로 내려받습니다.

어떤 태그가 어떻게 바뀌나

  • h1~h6 → 슬라이드 제목, 소제목
  • p → 본문 문단, strong·em·code의 강조는 그대로 유지
  • ul·ol → 글머리 목록, 중첩 목록은 단계별 들여쓰기
  • table → 표 (머리행 색 채움)
  • img·figure → 그림과 설명글
  • pre·code → 고정폭 코드 상자
  • blockquote → 인용 상자
  • aside class="notes" → 발표자 노트

판형 고르기

가운데 위 판형 상자에서 슬라이드(16:9·16:10·4:3), 인쇄 문서(A4·A3), 학회 포스터(A0·A1·A2)를 고릅니다. 포스터를 고르면 조판 방식이 바뀝니다. 각 장이 구역이 되어 여러 단에 이어 흐르고, 맨 위에 제목 배너가 붙습니다. 표지에 넣은 제목·부제·발표자가 배너에 들어갑니다.

  • 단 수 2~4단이 일반적입니다. A0 세로는 3단, A0 가로는 4단이 무난합니다.
  • 글자 배율 1.0이면 A0 기준 본문 28pt로, 학회 포스터의 표준 크기입니다.
  • 한 장에 꽉 채우기 단 수와 배율을 함께 찾아 한 장에 가장 알차게 맞춥니다.
  • 내용이 한 장을 넘으면 다음 쪽으로 이어집니다. 실제 인쇄 전에 쪽수가 1인지 확인하세요.

인쇄용 PDF가 필요하면 PDF로 인쇄를 누르고 대상을 PDF로 저장으로 고르세요. 용지 크기는 판형에 맞춰 자동 지정됩니다.

그림이 안 들어올 때

다른 사이트의 그림 주소는 브라우저가 막는 경우가 있습니다. HTML 안에 data: 형식으로 넣거나, 그림과 HTML을 같은 폴더에 두고 파일로 열면 확실합니다.

마크다운

마크다운을 붙여넣으면 자동으로 알아보고 HTML로 바꾼 뒤 변환합니다. 제목·목록·표·인용·코드·굵게·기울임을 지원합니다.

내 문서는 어디로 가나

어디로도 가지 않습니다. 변환·미리보기·PPTX 만들기 모두 브라우저 안에서 끝납니다. 작업 내용은 이 브라우저에만 임시로 남습니다.
