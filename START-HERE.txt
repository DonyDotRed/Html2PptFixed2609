★ 열어야 할 파일은 index.html 하나입니다. (열쇠말: redpass)
  이 폴더의 index.html 안에 PPTX 엔진까지 전부 들어 있습니다.
  source 폴더는 고쳐 쓸 때만 필요합니다. 그 안의 파일은 열지 마세요.

■ GitHub Pages 에 올리기 — 파일 하나면 끝
  1) 저장소를 만듭니다.
  2) Add file → Upload files 로 index.html 을 끌어다 놓고 Commit.
  3) Settings → Pages → Branch: main / (root) → Save.
  4) 1~2분 뒤 https://<계정>.github.io/<저장소>/ 에서 열립니다.
     (바로 안 보이면 새로고침을 Ctrl+Shift+R 로 하세요. 캐시가 남습니다.)

■ 제대로 올라갔는지 확인하는 법
  화면 맨 아래 상태줄 오른쪽에 "엔진  내장 · 준비됨" 이라고 초록색으로 나오면 정상입니다.
  "없음" 이 뜨거나 노란 막대가 보이면, 지금 열고 있는 파일이 index.html 이 아닙니다.
  막대에 현재 파일 경로가 함께 표시되니 그것으로 확인하세요.

■ 폴더 구조
  index.html                    ← 이것만 올리면 됩니다 (엔진 내장, 580 KB)
  START-HERE.txt                이 파일
  README.md                     자세한 설명
  .nojekyll                     있으면 좋지만 없어도 됩니다
  source/editable-index.html    화면과 디자인 (고쳐 쓸 때)
  source/app.js                 변환기 · 조판 엔진 · 편집기
  source/lib/pptxgen.bundle.js  PPTX 엔진 원본
  source/build.py               고친 뒤 실행 → 상위 폴더 index.html 재생성
