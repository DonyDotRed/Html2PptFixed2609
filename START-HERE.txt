DECK·FORGE — HTML/마크다운을 PPTX(슬라이드 · A0 포스터)로 · 열쇠말 redpass

★ 어떤 파일을 쓸지
  index.html          (116 KB)  ← 기본. GitHub Pages 처럼 인터넷이 되는 곳
                                  PPTX 엔진을 인터넷에서 받아 씁니다.
  index-offline.html  (581 KB)     사내망·USB 등 인터넷이 막힌 곳
                                  엔진이 파일 안에 들어 있습니다.

  둘 다 파일 하나로 완결됩니다. 다른 파일은 필요 없습니다.

■ GitHub Pages 올리기
  1) 저장소 → Add file → Upload files
  2) index.html 을 "끌어다 놓기"로 올립니다.
     ※ 내용을 복사해서 웹 편집기에 붙여넣지 마세요. 큰 파일은 중간에 잘립니다.
  3) Commit → Settings → Pages → Branch: main / (root) → Save
  4) 1~2분 뒤 https://<계정>.github.io/<저장소>/ 접속. 안 바뀌면 Ctrl+Shift+R.

■ 잘 올라갔는지 보는 법
  화면 맨 아래 상태줄 오른쪽.
    "엔진  외부 · 준비됨"  → 정상 (웹판)
    "엔진  내장 · 준비됨"  → 정상 (오프라인판)
    "엔진  없음"           → 위쪽 노란 막대에 원인이 적혀 있습니다:
        "HTML 파일이 잘렸습니다"      → 붙여넣기로 옮기다 잘린 것. 다시 올리세요.
        "내장 엔진이 실행되지 않았습니다" → 파일 손상. 다시 내려받으세요.
        "PPTX 엔진을 찾지 못했습니다"   → 인터넷 차단. deckforge-engine.js 를 같이 올리거나
                                       index-offline.html 을 쓰세요.
