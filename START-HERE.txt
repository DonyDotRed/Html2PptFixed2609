DECK·FORGE — HTML/마크다운을 PPTX(슬라이드 · A0 포스터)로

★ 열 파일은 index.html 하나입니다. 열쇠말은 redpass 입니다.
  나머지 파일은 고쳐 쓸 때만 필요합니다. 없어도 index.html 은 혼자 동작합니다.

■ GitHub Pages 에 올리기
  1) 저장소를 만듭니다.
  2) Add file → Upload files 로 index.html 을 끌어다 놓고 Commit.
     (이 폴더를 통째로 올려도 됩니다. 파일 이름이 겹치지 않습니다.)
  3) Settings → Pages → Branch: main / (root) → Save.
  4) 1~2분 뒤 https://<계정>.github.io/<저장소>/ 에서 열립니다.
     화면이 예전 것으로 보이면 Ctrl+Shift+R 로 강제 새로고침하세요.

■ 정상 여부는 화면 맨 아래 상태줄에서
  "엔진  내장 · 준비됨" 이 초록색으로 보이면 정상입니다.
  노란 막대가 보인다면 index.html 이 아니라 deckforge-shell.html 을 연 것입니다.

■ 이 폴더의 파일들 (전부 같은 위치, 하위 폴더 없음)
  index.html                     실행용. 엔진까지 들어 있는 완성본 (580 KB)
  deckforge-shell.html           편집용 화면. 혼자서는 PPTX 저장이 안 됩니다
  deckforge-app.js               변환기 · 조판 엔진 · 편집기 소스
  deckforge-engine.js            PPTX 생성 엔진 원본 (pptxgenjs, MIT)
  deckforge-build.py             위 셋을 합쳐 index.html 을 다시 만듭니다
  deckforge-engine-LICENSE.txt   엔진 라이선스 고지
  README.md                      자세한 설명
  .nojekyll                      있으면 좋지만 없어도 됩니다

■ 고쳐 쓰는 법
  deckforge-shell.html 이나 deckforge-app.js 를 고친 뒤,
  이 폴더에서  python3 deckforge-build.py  를 실행하면 index.html 이 새로 만들어집니다.
